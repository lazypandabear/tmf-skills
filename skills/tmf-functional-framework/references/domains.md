# Functional Framework Domains and Representative Application Areas

Classic TAM application areas. GB929F now decomposes these into function-level entries. Verify names against the target release.

| Domain | Representative application areas |
|---|---|
| Market/Sales | Campaign Management, Sales Force Automation, Channel Sales Management, Lead and Opportunity Management |
| Product | Product Catalog Management, Product Lifecycle Management, Pricing and Offer Configuration |
| Customer | Customer Information Management, Customer Order Management, Customer Problem Management, Customer Self-Service, Customer SLA Management |
| Customer: Billing and Revenue | Rating and Charging (online, offline), Bill Calculation, Bill Format and Render, Collection Management, Receivables Management, Billing Inquiry and Dispute |
| Service | Service Catalog Management, Service Inventory Management, Service Order Management, Service Activation and Configuration, Service Problem Management, Service Quality Management, Service Test |
| Resource | Resource Inventory Management, Resource Order Management, Resource Activation (domain managers, controllers), Fault (Alarm) Management, Performance Management, Resource Mediation, Network Planning and Design, Workforce Management, Resource Test |
| Supplier/Partner | Partner Management, Partner Settlement, Supplier Order Management, Partner Onboarding |
| Enterprise | Finance and ERP, HR, Revenue Assurance, Fraud Management, Enterprise Risk |
| Integration and Common | Integration infrastructure (API gateway, event bus), Data and Analytics, Identity and Access, Document Management |
