# Autonomous Network Levels

Level names follow TM Forum IG1218/IG1252, aligned with 3GPP TS 28.100. Definitions below are paraphrased summaries. Use IG1252 for formal criteria.

| Level | Name | Summary |
|---|---|---|
| L0 | Manual Operation & Maintenance | Humans perform all tasks. Tools display data only. |
| L1 | Assisted Operation & Maintenance | Systems execute repetitive sub-tasks from preset rules. Humans analyze and decide. |
| L2 | Partial Autonomous Network | Closed loops for specific units under defined conditions. Humans handle the rest. |
| L3 | Conditional Autonomous Network | System senses changes and adapts within a domain. Humans approve or handle exceptions. |
| L4 | High Autonomous Network | System runs predictive or active closed loops across domains, driven by service and customer experience. |
| L5 | Full Autonomous Network | Closed-loop autonomy across all services, domains, and the full lifecycle. Directional goal. |

## Task scoring grid
| Task | Stage | L0 | L1 | L2 | L3 | L4 | L5 |
|---|---|---|---|---|---|---|---|
| Intent or experience translation | Intent | Human | Human | Human | Human with system support | System | System |
| Data collection and monitoring | Awareness | Human | System-assisted | System | System | System | System |
| Root cause and impact analysis | Analysis | Human | Human | System-assisted | System | System | System |
| Remediation choice | Decision | Human | Human | Human | System, human approval | System | System |
| Execution of change | Execution | Human | System-assisted | System | System | System | System |

The grid is a working simplification for scoping. Formal scoring follows IG1252.

## Industry position
- Most CSPs report L1 to L2 across workflows. Source: Nokia Bell Labs Consulting, autonomous networks current state.
