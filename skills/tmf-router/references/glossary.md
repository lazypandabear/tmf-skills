# TMF Glossary

## Document series prefixes
| Prefix | Meaning | Example |
|---|---|---|
| GB | Guidebook (framework body) | GB921 eTOM, GB922 SID, GB929 Functional Framework |
| IG | Introductory Guide | IG1252 AN Levels Evaluation, IG1171 ODA Component Definition |
| TR | Technical Report | |
| TMF + 3 digits | Open API specification or poster | TMF622 Product Ordering, TMF630 API Design Guidelines |
| TMFC + 3 digits | ODA Component specification | TMFC028 Party Management |

## Terms
| Term | Definition |
|---|---|
| ABE | Aggregate Business Entity. A cluster of related SID entities inside a domain. |
| AN | Autonomous Networks. TMF framework for self-operating networks. |
| ANL | Autonomous Network Level, L0 to L5. |
| BSS | Business Support Systems. Customer, product, order, billing. |
| Canvas | ODA runtime environment, Kubernetes-based, that hosts ODA Components. |
| CFS | Customer Facing Service. Service visible to the customer as part of a product. |
| CSP | Communications Service Provider. |
| CTK | Conformance Test Kit. Automated test suite for Open API or ODA Component conformance. |
| Decoupling & Integration | ODA functional block that isolates the other blocks via APIs and events. |
| eTOM | enhanced Telecom Operations Map. Business Process Framework, GB921. |
| FAB | Fulfillment, Assurance, Billing. Vertical end-to-end groupings in eTOM Operations. |
| Functional Framework | Successor view of TAM. Function-level decomposition, GB929F. |
| Intent | Declarative statement of a desired outcome, without the method. Used in AN. |
| ODA | Open Digital Architecture. Component-based target architecture. |
| ODF | Open Digital Framework. Umbrella for ODA and the core frameworks. |
| OPS | Operations. eTOM Level 0 area for run-time processes. |
| OSR | Operations Support & Readiness. eTOM OPS vertical. |
| OSS | Operations Support Systems. Service, resource, network, assurance. |
| RAND | Reasonable and non-discriminatory. TM Forum IPR mode for most documents. |
| RFS | Resource Facing Service. Internal service that realizes a CFS on resources. |
| SID | Shared Information/Data model. Information Framework, GB922. |
| SIP | Strategy, Infrastructure & Product. eTOM Level 0 area for planning and lifecycle. |
| TAM | Telecom Application Map. Application Framework, GB929. |
