# Value Stream Template

Official structure: GB1029V TM Forum Value Stream Framework.

## Header
| Field | Content |
|---|---|
| Value stream name | Verb-noun, stakeholder view. Example: "Acquire Connectivity Service" |
| Initiating stakeholder | Who starts it |
| Trigger | Event that starts it |
| Value proposition | Outcome the stakeholder receives |
| Success metric | One measurable outcome. Example: order-to-activation lead time |

## Stages
| # | Stage | Entrance criteria | Exit criteria | Value item | Enabling capabilities | Realizing eTOM processes | Systems / APIs |
|---|---|---|---|---|---|---|---|
| 1 | | | | | | | |
| 2 | | | | | | | |

## Generic example (illustrative)
| # | Stage | Value item | Realizing eTOM processes |
|---|---|---|---|
| 1 | Explore offers | Relevant offer shown | Customer Interface Management, Selling |
| 2 | Confirm eligibility | Serviceable address confirmed | Selling (qualification) |
| 3 | Commit order | Accepted order | Order Handling |
| 4 | Deliver service | Working service | Service Configuration & Activation, Resource Provisioning, Workforce Management |
| 5 | Start billing | First accurate bill | Bill Invoice Management |

## Rules
- Stages are stakeholder-visible outcomes, not internal steps.
- Allow skip, repeat, and early exit per the flow adaptability principle.
